# Contribution guide

- Start only after the organiser announces kick-off.
- Reproduce each issue before coding.
- Use focused branches: `fix/issue-<number>-<summary>` and `feature/<short-name>`.
- Run `python -m pytest -q`; never delete, skip or weaken tests.
- Pull requests should include root cause, summary, tests run and known limitations.
- Be ready to explain and modify your code during the viva.
